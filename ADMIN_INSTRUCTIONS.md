# Инструкция по использованию админки для управления консультантами

## 🚀 Как зайти в админку

1. **Запустите проект локально:**
   ```bash
   docker-compose up -d
   ```

2. **Откройте админку в браузере:**
   ```
   http://localhost:8000/admin
   ```

3. **Войдите в систему:**
   - Используйте учетные данные суперпользователя
   - Если у вас нет суперпользователя, создайте его через Django shell или FastAPI

## 📋 Структура админки

### 1. Категории консультантов (Consultant Categories)
- **Гастроэнтерологи** (Gastroenterologists)
- **Диетологи** (Nutritionists) 
- **Психологи** (Psychologists)

### 2. Консультанты (Consultants Extended)
Основная модель для управления консультантами со всеми необходимыми полями.

### 3. Услуги консультантов (Consultant Services)
Услуги, которые предоставляет каждый консультант.

### 4. Отзывы консультантов (Consultant Reviews)
Отзывы пациентов о работе консультантов.

## 🔧 Как добавить консультанта

### Шаг 1: Создание консультанта

1. Перейдите в раздел **"Консультанты (расширенные)"**
2. Нажмите **"Создать"**
3. Заполните обязательные поля:

#### Основная информация:
- **Полное имя (RU)** - ФИО на русском языке
- **Полное имя (EN)** - ФИО на английском языке
- **Категория** - выберите из списка (Гастроэнтерологи/Диетологи/Психологи)
- **Фотография** - URL или путь к изображению

#### Описания (2 штуки):
- **Описание 1 (RU)** - основное описание на русском
- **Описание 1 (EN)** - основное описание на английском
- **Описание 2 (RU)** - дополнительное описание на русском
- **Описание 2 (EN)** - дополнительное описание на английском

#### Образование:
- **Образование (RU)** - информация об образовании на русском
- **Образование (EN)** - информация об образовании на английском

#### Опыт работы:
- **Стаж работы** - количество лет опыта (число)
- **Количество научных работ** - количество научных публикаций (число)

#### Медиа контент:
- **Видео презентация** - URL видео файла (если есть)
- **Фотогалерея** - массив URL фотографий (если есть)
- **Документы** - массив URL документов/сертификатов (если есть)

#### Статус:
- **Активен** - отображать ли консультанта на сайте
- **Рекомендуемый** - показывать ли в топе

4. Нажмите **"Сохранить"**

### Шаг 2: Добавление услуг

1. Перейдите в раздел **"Услуги консультантов"**
2. Нажмите **"Создать"**
3. Заполните поля:
   - **Консультант** - выберите созданного консультанта
   - **Название (RU)** - название услуги на русском
   - **Название (EN)** - название услуги на английском
   - **Описание (RU)** - описание услуги на русском
   - **Описание (EN)** - описание услуги на английском
   - **Цена** - стоимость услуги в рублях (опционально)
   - **Длительность (минуты)** - продолжительность услуги (опционально)
   - **Порядок сортировки** - для упорядочивания услуг
   - **Активна** - отображать ли услугу

4. Нажмите **"Сохранить"**

### Шаг 3: Добавление отзывов

1. Перейдите в раздел **"Отзывы консультантов"**
2. Нажмите **"Создать"**
3. Заполните поля:
   - **Консультант** - выберите консультанта
   - **Имя рецензента** - имя автора отзыва
   - **Рейтинг** - оценка от 1 до 5 звезд
   - **Дата отзыва** - дата написания отзыва
   - **Текст отзыва (RU)** - текст отзыва на русском
   - **Текст отзыва (EN)** - текст отзыва на английском
   - **Опубликован** - показывать ли отзыв на сайте
   - **Рекомендуемый** - выделить ли отзыв

4. Нажмите **"Сохранить"**

## 📁 Работа с файлами

### Хранение файлов
- **Фотографии** - сохраняются как URL (рекомендуется использовать облачное хранилище)
- **Видео** - сохраняются как URL (рекомендуется YouTube, Vimeo или облачное хранилище)
- **Документы** - сохраняются как URL (PDF файлы в облачном хранилище)

### Рекомендации по файлам:
1. **Фотографии консультантов**: 300x400px, формат JPG/PNG
2. **Фотогалерея**: любые размеры, формат JPG/PNG
3. **Видео**: MP4 формат, до 100MB
4. **Документы**: PDF формат

## 🌐 Многоязычность

Все текстовые поля поддерживают два языка:
- **RU** - русский язык
- **EN** - английский язык

**Важно:** Заполняйте оба языка для корректного отображения на сайте.

## 🔍 API Endpoints

После добавления консультантов они автоматически становятся доступны через API:

- `GET /api/v1/consultants-extended/categories` - получить категории
- `GET /api/v1/consultants-extended/consultants` - получить всех консультантов
- `GET /api/v1/consultants-extended/consultants/{id}` - получить консультанта по ID
- `GET /api/v1/consultants-extended/consultants/{id}/services` - получить услуги консультанта
- `GET /api/v1/consultants-extended/consultants/{id}/reviews` - получить отзывы консультанта

## 🎯 Фронтенд интеграция

Консультанты автоматически отображаются на:
- **Странице консультантов** (`/consultants`) - список всех консультантов
- **Детальной странице консультанта** (`/consultants/{id}`) - полная информация

### Особенности отображения:
- Если не добавлено видео - секция "Знакомство с врачом" не показывается
- Если не добавлены фото в галерею - секция "Фотогалерея" не показывается
- Если не добавлены документы - вкладка "Документы" не показывается
- Отзывы показываются только если они опубликованы

## ⚠️ Важные замечания

1. **Обязательные поля:** ФИО на обоих языках и категория
2. **Активность:** Неактивные консультанты не отображаются на сайте
3. **Переводы:** Всегда заполняйте оба языка для корректной работы
4. **Файлы:** Используйте надежное облачное хранилище для медиа файлов
5. **Рейтинг отзывов:** Только от 1 до 5 звезд

## 🆘 Поддержка

При возникновении проблем:
1. Проверьте логи Docker контейнеров
2. Убедитесь, что все обязательные поля заполнены
3. Проверьте корректность URL файлов
4. Убедитесь, что консультант активен
